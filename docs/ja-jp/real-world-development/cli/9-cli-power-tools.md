多くの優れた CLI ツールと同様に、GitHub Copilot CLI にも操作用のスラッシュ コマンドが用意されています。高度な機能、内部情報、追加の構成オプションを利用できます。すでに `/diff`、`/mcp`、`/skills`、`/agent`、`/pr` などのコマンドを使いました。ここでは、他の便利なコマンドをいくつか確認します。

このレッスンでは、次のことを行います。

- `/context` と `/compact` を使って、Copilot が会話のコンテキストを管理する方法を確認します。
- `/model` で利用可能なモデルを確認します。
- `/share` でセッションをエクスポート、共有する方法を学びます。
- 並列作業、worktree、クラウド エージェントへの委任に使う任意のコマンドを確認します。

## シナリオ

CLI の中心的なワークフローが完了しました。次は、コンテキスト管理、モデルの切り替え、セッション共有、[Copilot クラウド エージェント][about-cloud-agent]への任意の委任など、いくつかの機能を確認します。

## Copilot CLI のコンテキストを確認する

大規模または複雑なタスクを扱うと、モデルのコンテキスト ウィンドウの上限に達することがあります。Copilot CLI は必要に応じて会話を自動的に圧縮します。スラッシュ コマンドを使うと、状態を確認して手動で圧縮することもできます。

1. Codespace に戻り、Copilot CLI が開いていない場合は、リポジトリのルートから起動します。
2. 次を入力します。

   ```plaintext
   /context
   ```

3. モデル、現在のトークン使用量、システム指示、ツール、メッセージ、空き容量へのコンテキストの配分を確認します。
4. 会話を圧縮します。

   ```plaintext
   /compact
   ```

5. もう一度 `/context` を入力して結果を比較します。会話が短い場合、大きな違いがないこともあります。

> [!NOTE]
> コンテキスト ウィンドウがいっぱいになると、Copilot CLI は自動的にコンテキストを圧縮します。タイミングを選びたい場合は `/compact` を使います。無関係なタスクに切り替えて会話を新しくしたい場合は、`/clear` または `/new` を使います。

## モデルを選択する

モデルごとに得意分野が異なり、開発者ごとに好みも違います。Copilot CLI では、利用できるモデルを表示し、使うモデルを選択できます。

1. 次を入力します。

   ```plaintext
   /model
   ```

2. 利用可能なモデルと使用量に関する情報を確認します。
3. 現在のモデルを使い続けるか、別のモデルを選ぶか、<kbd>Esc</kbd> を押して一覧を閉じます。

## セッションを共有する

チームで協力して学んだことを共有すると、AI ツールの活用方法を改善できます。`/share` コマンドを使うと、セッションを Markdown または HTML ファイルとしてエクスポートし、共有リンクを作成したり、GitHub gist として公開したりできます。

1. `/help` を入力し、インストール済みバージョンでの `/share` のオプションを確認します。
2. セッションを共有する場合は、ローカルの Markdown ファイルへのエクスポートに使う `/share file` など、目的に合った方法を選びます。
3. エクスポートした内容を送信または公開する前に確認します。セッションのエクスポートには、プロンプト、応答、プロジェクトの詳細が含まれる場合があります。

リンクや gist の公開は任意です。チームが共有する予定のないリポジトリや会話の内容を公開しないでください。

## 任意: 作業を拡張または委任する

ワークショップの中心的な内容は完了しました。大きなタスクには、Copilot CLI の次のコマンドも利用できます。

- `/fleet` は、独立したサブタスクを複数のサブエージェントに分割して並行実行できます。
- `/worktree` は、別のタスク用に分離した Git worktree を作成できます。
- `/delegate` はタスクを Copilot クラウド エージェントに送信できます。クラウド エージェントは非同期で作業し、プルリクエストを作成する場合があります。

これらのコマンドを使うと追加の worktree やリモート作業が発生する可能性があるため、任意です。試す場合は、新しく範囲を明確に定めたタスクから始め、通常のワークフローに沿って結果をレビューしてください。非同期エージェントによる作業をさらに学びたい場合は、[クラウド エージェントのワークショップ][cloud-workshop]に進みます。
