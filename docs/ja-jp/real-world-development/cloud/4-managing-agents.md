ここまでの演習では、ユーザー エクスペリエンスの改善や機能追加を目的に、Copilot クラウド エージェントに 3 つのタスクを依頼しました。クラウド エージェントは非同期かつ自律的に動作しますが、タスクの進捗を監視することも重要です。

クラウド エージェントに割り当てたタスクは、GitHub.com の[エージェント ページ][agents-page]など、さまざまなツールで管理できます。このミッション コントロールでは、オープンなプルリクエスト (PR) があるすべてのエージェント タスクを確認できます。実行した操作を調べたり、進行中のセッションを誘導したりすることもできます。

このレッスンでは、次のことを行います。

- エージェント ページを使ってクラウド エージェントのタスクを監視します。
- 進行中のセッションを誘導し、機能の追加を依頼します。

## シナリオ

エージェントにハイ コントラスト モードを作成するよう依頼した後、チームはライト モードも追加することにしました。サイトのスタイル更新と切り替え機能の追加を進めているため、ライト モードも含めるのが合理的だと判断しました。エージェントの作業を誘導し、ハイ コントラストに加えてライト モードも追加します。

## Copilot クラウド エージェントのタスクを確認する

Copilot クラウド エージェントに割り当てたすべてのタスクの現在の状態を確認しましょう。

1. [Copilot エージェント ページ](https://github.com/copilot/agents)に移動します。
2. メイン ペインと左ペインにあるタスクの一覧を確認します。次のような、割り当てたタスクが表示されます。
    - コードベースのドキュメントを更新しています。
    - ゲームを変更するための API を生成しています。
    - Web サイトにハイ コントラスト モードを追加しています。
3. 実行中のタスクを選択し、Copilot が実行した作業を確認します。次のような作業が含まれます。
    - リポジトリからコードをチェックアウトします。
    - Copilot が作業するための環境を作成します。
    - MCP サーバーをセットアップします。
    - 割り当てられたタスクを完了するためのさまざまな手順を実行します。

> [!NOTE]
> 表示される手順は、Copilot の作業状況や採用した方法によって異なります。

4. 右側に表示されるプルリクエスト (PR) ペインも確認します。ここから PR と変更されたファイルを確認し、さらに監視できます。

## クラウド エージェントを誘導する

実行中のタスクを確認したので、クラウド エージェントがハイ コントラスト モードに取り組んでいる間に、ライト モードの切り替えも含めるよう依頼します。

1. ハイ コントラスト モードの追加に関するセッションを選択します。正確なタイトルは Copilot が選んだ名前や現在の作業状況によって異なります。

    ![ミッション コントロールのアクセシビリティ セッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、作業を開始したことを示すまで、数分間セッションを確認します。次のようなメッセージが表示されたら作業開始の目安です。
3. **Steer active session while Copilot is working** ダイアログに、次のプロンプトを入力します。

    ```plaintext
    While we are working on a high contrast mode, let's also add a light mode. There should be a switch for this mode as well where users can select their desired display mode.
    ```

    ![エージェント ページのクラウド エージェント タスクで、Steer active session while Copilot is working ダイアログが強調表示されたスクリーンショット](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトを受け取り、作業計画に含めたことを確認します。

## Copilot に作業を任せる

Copilot は更新されたタスクに取りかかります。メッセージを送った時点で実行中の手順が完了すると、新しい依頼を作業に取り入れます。

これまでと同じように、完了まで数分かかります。ここで一度立ち止まり、これまでに学んだことを振り返ってみましょう。

## まとめと次のステップ

このレッスンでは、GitHub Copilot クラウド エージェントのタスクを監視して誘導するための中心的な場所である、Copilot エージェント ページについて学びました。このミッション コントロールでは、進行中と完了済みのタスクを追跡し、実行内容を確認して、進行中のタスクの範囲を変更したり、追加のガイダンスを提供したりできます。

このレッスンでは、次のことを行いました。

- ミッション コントロールとエージェント ページを使ってクラウド エージェントのタスクを監視しました。
- 進行中のセッションを誘導して、機能の追加を依頼しました。

Copilot がアクセシビリティ機能の作業を進めている間に、Copilot が作成した[プルリクエストを反復改善][next-lesson]しましょう。
